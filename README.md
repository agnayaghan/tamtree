# TamTree LLC - Professional Consulting Website

Modern, responsive website for TamTree LLC - a premier technology consulting and staffing firm.

## 🚀 Live Demo

Visit the website: [TamTree LLC](https://tamtreellc.com)

## ✨ Features

- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop)
- **Modern UI/UX**: Clean, professional design with smooth animations
- **3D Effects**: Interactive card hover effects with depth
- **Technologies Showcase**: Auto-scrolling marquee featuring our tech stack
- **Performance Optimized**: Lazy loading, optimized images, fast load times
- **Multi-Page**: Complete website with Home, About, Services, Training, and Contact pages

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, 3D Transforms)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Poppins)
- Unsplash Images

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/anandpappannan/TAMTREE.git
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   python3 -m http.server 8000
   ```

3. Visit `http://localhost:8000`
